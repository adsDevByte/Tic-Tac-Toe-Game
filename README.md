# Tic Tac Toe

A two-player Tic Tac Toe game built with React and Vite. Both players share the same device and take turns clicking the board.

## Tech Stack

- **Frontend** — React, Vite, CSS

## Features

- 3x3 interactive game board
- Two-player turn system on the same device
- Winner and draw detection with visual highlights
- Live scoreboard that persists across rounds
- Neon arcade UI with animations

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` to play.

## How to Play

1. Player 1 is **X**, Player 2 is **O**
2. Take turns clicking empty cells
3. First to get 3 in a row wins the round
4. Click **Next Round** to play again — scores are kept
5. Click **Reset All** to clear the scoreboard
